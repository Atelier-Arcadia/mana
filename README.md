# mana

mana is a smol agent harness for running a smol language model :3

Currently, mana is being developed with [Devstral small 2](https://lmstudio.ai/models/mistralai/devstral-small-2-2512). This model happens to run reasonably well on my Radeon rx 9060 xt.

Not a single line of code or documentation is generated by a model, although I am using models occassionally to understand bugs and explore documentation etc.

This is a highly personalized software project not necessarily intended to be adopted by others. It's something I'm building
more to learn about agent harnesses and how to get the most out of small language models for my own use rather than to
build something that other people will gel with.
